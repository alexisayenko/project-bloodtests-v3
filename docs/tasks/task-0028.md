# Add an Edit Panels mode -- hide/show, custom panels, drag-and-drop reorder

Split out of task-0023 on 2026-09-14, since this is an entirely separate,
unbuilt body of work from the two already-shipped display-control features
task-0023 covers now (Compact view and Status Filter toggles).

## 1. Allow to Edit Panels View (`Edit Panels Mode`)

Add an **Edit Panels** button to the toolbar to customize the panel grid:

### 1.1 Hide / Show Panels
- In edit mode, each panel card displays a visibility toggle (e.g. Eye icon `👁 Visible` / `🚫 Hidden` or checkbox).
- Alternatively, provide an "Organize Panels" drawer/modal listing all panels with checkboxes to show/hide.
- Hidden panels are removed from the default grid and sidebar navigation, letting users focus only on panels relevant to their health monitoring.
- A "Hidden Panels" counter / drawer allows unhiding any panel at any time.

### 1.2 Create Custom Panels
- **"+ New Panel"** button in edit mode or toolbar.
- Builder modal / interface:
  - **Panel Name & Category**: e.g., "Longevity Protocol", "Cardiovascular Deep-Dive".
  - **Icon & Accent Color**: Visual icon selector and theme color.
  - **Description**: Target condition or clinical rationale.
  - **Marker Picker**: Search and select any analyte from the catalog (by LOINC, friendly name, or short name) or computed index.
- Custom panels appear alongside standard panels in the grid with an edit/delete option.
- Stored locally in browser storage and round-tripped through backup JSON/zip export.

### 1.3 Reorder Panels by Dragging (Drag-and-Drop)
- In edit mode, panel cards become draggable with a visible grab handle (`GripVertical`) and hover/active states.
- Reordering panels updates the grid layout in real time.
- The custom sort order (`panelOrder: string[]`) is persisted in `localStorage`.
- Provide accessible keyboard reorder controls (Move Earlier / Move Later) as a fallback.
- "Reset Order" action to restore standard clinical grouping.
