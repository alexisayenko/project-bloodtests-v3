# Add the interchange JSON Schema file to the repo

A draft JSON Schema (2020-12) for the v3 envelope exists from chat:
envelope with `schema`/`diagnosticReports` required, observation with
`loinc` (empty allowed) + `name` required and value-or-rawValue via
`anyOf`, mirroring the validator. Land it, link it from
`interchange-format.md`, and consider referencing it from the chatbot
prompt so chatbots can self-validate their output.

Shipped 2026-09-07, with one deviation from the proposal above: the
file landed as `web/public/schema/bloodtests-3.schema.json` rather than
under `docs/`, because a schema is only useful to an outside reader if
it has a stable URL — it is served from
`https://blood.isayenko.net/schema/bloodtests-3.schema.json` and named
for the envelope version it describes. It covers version 3 only (the
upload parser still accepts `1`), leaves objects open so an added
optional field doesn't invalidate old readers, and is held to the
exporter's real output by `web/test/envelope-schema.test.ts` (ajv, a
devDependency only — nothing schema-related is bundled).
[`interchange-format.md`](../tech/interchange-format.md) links it from
its first paragraph.
