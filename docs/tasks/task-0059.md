# Draw the testosterone and inhibin B feedback arrows on Hormonal Pathways

task-0024's spec gives the gonadal axis four negative-feedback arrows
([task-0024 §4.0](task-0024.md#40-edges)): T → ↓Kp, E2 → ↓Kp, E2 → ↓LH and
Inhibin B → ↓FSH, each with its own citation. Only estradiol's is built, as one
arrow into the brain image ([task-0057](task-0057.md)).

## What to build

- **T → ↓Kp**: from the central T to the brain, acting at the Kp neurons of the
  arcuate nucleus through the androgen receptor, never the GnRH neurons.
- **Inhibin B → ↓FSH**: from the Sertoli cells' inhibin B to FSH. Inhibin B is
  not drawn yet, so it needs a node first, with a value only when a reading
  exists.
- Both in the style [task-0057](task-0057.md) settles for feedback arrows,
  measured and re-measured like the existing arrows, each carrying a cited
  source.
