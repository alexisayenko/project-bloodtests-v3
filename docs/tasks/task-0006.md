# Match LOINC suggestions against catalog translations

Suggestion scoring compares only the Latin-script part of the printed
name against catalog English names, so a purely Greek- or
Russian-named test with no code gets no suggestions. The catalog
already carries `lang` translations per analyte — include them in the
token match (with the same IDF weighting) so non-English printed names
resolve too.
