# Per-code allowed-unit sets and alias-group collapse

The curated unit table assumed one unit per LOINC, so a legitimate
alternate scale (Estradiol 1848-1 in pg/mL) drew a false unit
warning, and alias codes of one analyte produced duplicate
suggestions. Added `ALLOWED_UNITS` (extra accepted units per code)
and `SUPPLEMENTARY_UNITS` (units for catalog analytes outside the
curated table) in `loincCheck.ts`; the validation unit warning now
fires only when `unitAllowed()` is false and lists the full
accepted set. Alias-group members collapse into a single
suggestion — the kept code is the member whose known unit matches
the row's (SHBG nmol/L → 13967-5), same-scale groups falling back
to the primary — and a printed code that is an alias of the
confident derivation counts as a match.
