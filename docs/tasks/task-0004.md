# Use sex and birth year to select sex- and age-banded reference ranges

> **Partial progress (2026-09-11).** Sex is now read from Database details for computed indices only: an index may carry `bandsBySex` (`web/src/data/computedIndices.ts`, `indexBands` / `indexZone`), and `biot` (bioavailable testosterone) is judged against Mayo Clinic Laboratories' limits for the set sex, with no status while sex is unset. Printed reference ranges are still not selected among, and `birthYear` is still unread — `biot`'s age-banded men's limits are folded into its borderline zone instead.

Database details now stores `sex` and `birthYear`, and v3 reference
ranges carry `appliesTo: {sex}` and `ageLow`/`ageHigh`, but nothing
selects among multiple printed ranges yet (Ygia FSH/LH/E2 print five
female bands plus a male band per test). Pick the applicable range at
display time: sex from envelope meta, age = birthYear vs the report's
collectedAt. Fall back to showing the printed range text when neither
is set, per the interchange spec.
