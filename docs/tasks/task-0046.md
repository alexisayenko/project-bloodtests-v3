# Add cFT (Nanjee-Wheeler) as a fifth calculated free-T variant

Alex supplied a fifth calculated free-testosterone (cFT) formula, not
previously tracked anywhere in this repo:

**Nanjee-Wheeler Equation (1985)** — an empirical log-linear
regression that omits albumin entirely:

```
ln([FT]) = 1.053 * ln([TT]) - 1.051 * ln([SHBG]) - 2.82
```

Note: all hormone inputs (TT, SHBG) must be in nmol/L for the
natural-log outputs to scale correctly.

Source: <https://www.endocrine-abstracts.org/ea/0010/ea0010p76>

## Why this is a genuinely new addition

This is a **fifth** cFT variant, not a fill-in for an existing
"unavailable" slot. Vermeulen (`cft`) and Ly & Handelsman (`cftlh`)
are already implemented; Sartorius and Zakharov are tracked in
`HormonalPathwaysView.tsx`'s `BADGES` array as `unavailable: true`
placeholders (no formula implemented / paywalled coefficients /
independently reported inaccurate). Nanjee-Wheeler has no existing
placeholder — it needs a brand-new badge slot added to `BADGES`, not
an `unavailable` flag flipped.

Unlike Vermeulen (needs T, SHBG, albumin) and Ly & Handelsman (needs
T, SHBG only, two branches split on T), Nanjee-Wheeler is the
**simplest** of the three: one formula, two inputs (T, SHBG), no
albumin, no branching.

## What the code says

`web/src/data/indexDefs.ts`'s current cFT-related lineup (exact keys,
confirmed by reading the file):

- `cft` — "Free testosterone (calculated, Vermeulen)", inputs
  `T`, `SHBG`, optional `ALB`, formula solves the Vermeulen
  equilibrium-binding quadratic.
- `cftlh` — "Free testosterone (calculated, Ly & Handelsman)", inputs
  `T`, `SHBG` only, two-branch empirical polynomial split on
  T ≥ 5 nmol/L.
- `biot` — "Bioavailable testosterone", also built on the Vermeulen
  quadratic (free T × (1 + Ka·albumin)).
- `fai` — "Free androgen index", the older raw-ratio (T/SHBG × 100)
  alternative, explicitly described in its own `consensus` text as
  inferior to cFT.

Each is an `IndexDef` with `fn`, `references`, `evidenceLevel`,
mirrored by golden-master tests in `web/test/computed-indices.test.ts`
(e.g. `cft`'s and `cftlh`'s own `describe` blocks). A Nanjee-Wheeler
`cftnw` (or similar key) would follow the same shape: `fn` computing
the log-linear regression, `references` citing the abstract above,
`evidenceLevel` graded appropriately (an unreplicated 1985 conference
abstract, not a peer-reviewed journal formula like Vermeulen or
Ly & Handelsman — this task doesn't decide the grading, just flags
that the source is thinner than the other two).
