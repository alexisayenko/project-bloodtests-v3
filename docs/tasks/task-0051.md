# Show lab name and trim decimals in the What's-in-range chart tooltip

Alex requested this in chat on 2026-09-14 against a screenshot of the
"What's in range" chart's tooltip (Panel Detail / All Observations,
built from the vendored `<lab-explore>` component): "on the same chart
- in popup show name of lab / also - cut digits after dot in values".
No task file was created for it at the time; retroactively logged here
on 2026-09-15 once Alex flagged the gap.

## Two parts

1. **Show the lab name** for each dated reading in the tooltip,
   alongside the date already shown.
2. **Trim decimals** in the displayed values/percentages — a follow-up
   screenshot on 2026-09-15 showed a raw unrounded reading
   ("158.53224 mg/dL") still reaching the tooltip, confirming this
   isn't done yet either.

## Implementation (2026-09-15)

`ResultEntry.place` (already populated from each diagnostic report's
`laboratory` field) was already threaded through the app but unused in
the explore chart. Wired it in and trimmed decimals to match the app's
existing magnitude-based precision rule:

- `web/src/vendor/lab-explore/explore-types.ts` — widened
  `ExploreMarker.data` from `[string, number][]` to
  `[string, number, string?][]` (date, value, optional lab).
- `web/src/components/conditions/exploreModel.ts` — `buildTestMarker`
  now pushes `namedLab(e.place)` (the existing `ui.ts` helper that
  filters out placeholders like "Unknown Lab") as the tuple's third
  element.
- `web/src/vendor/lab-explore/lab-explore.ts` — a `#labs` parallel
  lookup alongside `#buildData()`'s existing `#abs`; the tooltip
  appends `· <lab>` when known. Added a local `fmtVal()` mirroring
  `web/src/utils/format.ts`'s `decimalsFor` (>=100 -> 0 decimals, >=10
  -> 1, >=1 -> 2, else 3) — duplicated rather than imported since this
  is vendored code, same "deliberate, scoped exception to vendor-as-is"
  precedent as the earlier MMM YY date-format change. Used in both the
  tooltip and the uPlot legend, replacing the previously-unrounded
  value.
- `web/test/explore-model.test.ts` — updated fixtures for the new
  3-element tuple shape.

Computed indices (`LDL-C (F)/(S)/(MH)`) deliberately show no lab in the
tooltip — they're calculated, not lab-reported, matching the existing
"· Calculated" convention in `Popup.tsx`'s index popup. Threading a lab
through for indices would need bigger plumbing with no existing
precedent.
