# Round-trip envelope metadata on import

Export writes `generatedAt`, `subject`, `sex`, `birthYear`, `notes`
into the envelope, but import ignores all of them — re-importing an
exported file leaves the Database details form empty. Read these
fields in the v3 parse path and seed the stored envelope meta
(imported file replaces stored meta on the replace path; decide
merge-path semantics when adding a single report that carries them).
