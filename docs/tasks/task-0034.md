# Specify the Thyroid (HPT) and Adrenal (HPA) Hormonal Pathways axes

task-0024 built the Hormonal Pathways section's first axis, Gonadal (HPG).
Its "Where it lives" section already reserves the other two: "**Thyroid
(HPT)** and **Adrenal (HPA)** — later phases, not in this delivery. A tab is
added when its axis is built; until then `#pathways/hpt` and `#pathways/hpa`
fall back to `hpg` like any unknown segment." This task is to write the HPT
and HPA equivalent of task-0024's section 2 (ontology) and section 3.1/4
(the HPG spec and Mermaid wiring) — not to build the axes.

## What the code says

- `docs/tech/pathways/hpg.md`, the Mermaid wiring file task-0024 section 3
  names as the source of truth the build script (`pathways:build`, not yet
  implemented either) would parse, **does not exist in the repo yet** — only
  `docs/tech/decisions/adr-0014-pathway-wiring-is-mermaid-generated-to-json.md`
  (the decision to use Mermaid) exists under `docs/tech/`. The HPG Mermaid
  block itself currently lives inline in task-0024.md section 3.1, not yet
  extracted to its own file. So HPT/HPA specs should follow the same
  `docs/tech/pathways/<axis>.md` pattern once it's actually created — the
  file doesn't exist to copy from yet, only the convention task-0024
  describes.
- `web/src/components/conditions/HormonalPathwaysView.tsx` today renders
  only the HPG axis; there is no axis-tab switching, no `#pathways/hpt` or
  `#pathways/hpa` route handling, and no per-axis component split — task-0024
  confirms these routes still fall back to `hpg`.
- `web/src/components/conditions/hpAxisContent.ts`'s `HP_AXIS_HTML` (the
  Reference Book HP Axis page prose) **already contains cascade notation for
  both other axes**, seedable the way task-0024 drew on the Testosterone
  reference page for HPG:
  - Thyroid: `↓T4 → (Hypothalamus·ME)↓T3 → (Hypothalamus·PVN)↑TRH →
    (Pituitary)↑TSH → (Thyroid)↑T4 ⟲`.
  - Adrenal: `{stress} → (Hypothalamus·PVN)↑CRH → (Pituitary)↑ACTH →
    (Adrenal·ZF)↑Cortisol ⟲`, plus the crosstalk arrow
    `↑Cortisol → (Hypothalamus·POA)↓GnRH → (Pituitary)↓LH/FSH → (Testes)↓T`
    (already drawn into the HPG spec as `CORT -.->|"↓GnRH"| GNRH`, per
    task-0024 section 3.1 — so the HPA spec must stay consistent with that
    existing crosstalk edge rather than re-deciding it).
  - The prolactin brake (`↑PRL → (Hypothalamus·ARC)↓Kp → …`) is also already
    encoded on the HPG side (`PRL -.->|"↓Kp"| KP`); prolactin's own source
    (lactotrophs) and axis, if HPT/HPA end up needing to declare it as a
    first-class node, is undecided.
  - No molar-mass, catalog, or `INDEX_DEFS` entries were checked yet for
    which thyroid/adrenal markers (T4, T3, TSH, free forms; cortisol, ACTH)
    already exist as measurable analytes vs. which are unmeasured signals
    like GnRH/Kp — that check is part of the scoping this task asks for.

## The ask

This is a big, open-ended spec-writing task — do not write the full HPT/HPA
spec in this task file. Instead scope what needs deciding for each axis,
reusing task-0024 section 2's ontology rules (bands, signals, carriers,
enzymes, badges, lines) as the fixed vocabulary rather than re-deciding it:

- **Per axis, which hormones/signals are in scope** (e.g. HPT: TRH, TSH, T4,
  T3, rT3; HPA: CRH, ACTH, Cortisol, DHEA-S) and which measured markers
  already exist in the analyte catalog (`web/public/data/analyses.json`) vs.
  which are unmeasured intermediates (like GnRH/Kp in HPG).
- **Feedback loops and crosstalk** each axis carries, cross-checked against
  what `hpAxisContent.ts`'s existing prose already states and against the
  crosstalk edges HPG already commits to (Cortisol → GnRH, and any PRL/TSH
  interactions the current HP Axis page prose implies).
- **Carriers and conversions** analogous to HPG's SHBG/Albumin docking and
  5α-reductase/aromatase conversions — e.g. thyroid-binding globulin for T4,
  deiodinase conversion of T4 → T3.
- **Band layout and badges** per axis, following task-0024 section 2's
  drawn/not-drawn ontology (bands, signals, carriers, enzymes, badges,
  association vs. pathway-arrow lines) rather than introducing new node
  kinds.
- Confirms the deliverable is a `docs/tech/pathways/hpt.md` and
  `docs/tech/pathways/hpa.md` pair in the same Mermaid-wiring-spec pattern
  task-0024 established for `hpg.md` (section 3 of that task), once that
  pattern itself has a first concrete file to point to.
