# Add Scores -- simplified summary for users who don't want to dig into details

Alex's idea: a simplified layer on top of the app's existing detailed
results (Monitoring Panels, individual observations, computed
indices), for users who don't want to dig into every marker and
reference range themselves -- some kind of score(s) that roll results
up into something easier to read at a glance.

Not yet scoped. Open questions to work out before implementation:

- One overall score, or one per panel/condition (Hypogonadism,
  Cardiovascular Risk, etc.)?
- What does a score actually aggregate -- status counts (how many
  markers in/out of range), severity-weighted deviation from range,
  something else?
- How does this interact with the app's core design principle (see
  CLAUDE.md's "Key principle") that nothing shown is invented or
  silently altered, and a computed figure always carries a traceable
  citation/source -- a rolled-up "score" is a step further removed
  from what the lab printed than today's computed indices are, so its
  methodology needs to be as citable/transparent as everything else,
  or clearly labeled as a heuristic convenience rather than a clinical
  figure.
- Where does it live in the UI -- Monitoring Panels grid cards, a new
  top-level section, both?
