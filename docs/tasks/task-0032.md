# Display the signed-in account's name/email in the top bar

The desktop top bar (`TopBar.tsx`) is gone; `AccountView.tsx` already shows
the signed-in email, and Get Started (`ProfileView.tsx`) shows only generic
"Synced to your account" copy. Show the actual email where a signed-in line
is generic.

## What the code says

- **`useCloudSession` (`web/src/hooks/useCloudSession.ts`) returns the Worker's
  `GET /auth/me` answer, `{email, provider}`** (ADR-0027). There is no name
  or avatar: the Worker asks Apple for `scope=email` only and Google's ID
  token is read for `email` alone, so the display string is the email, with
  `'your account'` as the fallback. Showing a name would mean carrying it in
  the session cookie, which the Worker does not do today.
- **Only `AccountView.tsx` reads `user.email`**; `ProfileView.tsx` only
  branches on presence, so this task sets the convention.
