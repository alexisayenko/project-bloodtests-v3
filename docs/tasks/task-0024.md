# Add a Hormonal Pathways section, starting with the gonadal axis

Monitoring Panels and All Observations show each marker on its own: a row in
Results, a line in "What's in range", a ribbon in Charts. None of them shows
how the hormones of one axis drive and restrain each other. This task adds a
**Hormonal Pathways** section: one data-driven diagram per hormonal axis, with
the user's own values for a chosen month, so a low testosterone can
be read next to the LH that should be driving it and the estradiol and SHBG
around it. Its first axis, and the only one in this delivery, is the male
hypothalamic–pituitary–gonadal (HPG) axis.

The layout started from ChatGPT design mockups: one Alex shared on 2026-09-11,
and a revised one, produced from an image prompt drafted in chat the same day
and reviewed the same day too. They are a **visual style reference only** —
never a source for edges or biology; both had wiring errors (see
[Biology corrections](#31-biology-corrections-vs-the-mockups)). No image is
saved to the repo; this file and `pathways.json`
([2](#2-implementation-approach)) are the spec.

## 2. Implementation approach

- **Wiring source of truth: Alex's HP-axis notation** — the cascade notation
  of his homepage health/labs notes, carried today by the Reference Book HP
  Axis page (`HpAxisPage` in `ReferenceBookPage.tsx`, rendering the verbatim v2
  HTML in `hpAxisContent.ts`): signals, `(site · subsite)` targets,
  `{process}` conversions, ↑/↓ per edge, ⟲ closing a loop, and crosstalk.
- **It is encoded as data**: `web/public/data/pathways.json`, beside
  `analyses.json`, described by a closed-object, draft 2020-12 schema,
  `web/public/schema/pathways-1.schema.json`, and validated in
  `web/test/reference-data.test.ts` — ADR-0010's rule that reference data
  lives in JSON and is never mirrored in TypeScript.
  - Nodes reference analytes **by LOINC** and computed indices **by key**
    (`tlh`, `dhtt`, `te2`, `cft`, `biot`); a node with neither (GnRH, Kp,
    receptors, calculated pools) says what it is instead.
  - Edges carry source, target, mark (↑, ↓, or none for a receptor or the ⇄
    exchange), site / process, kind (forward, feedback, crosstalk, binding,
    exchange) and **a citation** — retrieved quote, URL and retrieval date, in
    the style of `indexDefs.ts`'s references and `molar-masses.json`'s
    sources.
  - The file carries **every chain the HP Axis page shows today** — HPT, HPG,
    HPA and their crosstalk — so its migration drops nothing, even though only
    the HPG diagram is built now.
- **Both consumers read that one file**, so they cannot drift:
  - the Reference Book HP Axis page — its cascade chains, now hand-written
    inside `HP_AXIS_HTML`, are migrated to render from `pathways.json` (the
    notation key and the surrounding prose may stay as they are);
  - the Hormonal Pathways diagram.
- **Layout**: an SVG drawn in code with hand-set coordinates per node per
  axis (in `pathways.json` or a small layout file,
  [10](#10-open-questions)), styled with the design tokens (`COLOR`); values,
  status colors and line thicknesses are applied from the user's data for the
  selected month. Not a generated image.
- **Mermaid was considered (2026-09-11) and rejected** for both the diagram
  and the Reference Book: its auto-layout cannot hold the banded layout, it
  has no animated transitions, per-edge styling and interaction are awkward,
  and it costs ~500 kB of bundle. Rendering is hand-laid SVG only.
- The mockups set visual style only; the edges below come from the notation.

## 3. Gonadal axis (HPG)

Horizontal bands, one per level of the axis, top to bottom:

| Band | Nodes | Notes |
| --- | --- | --- |
| Hypothalamus | Kp (`Hypothalamus·ARC`), GnRH (`Hypothalamus·POA—ME`); Cortisol as a side input | Kp → ↑GnRH. Neither Kp nor GnRH is measured in practice ([5](#5-missing-data)). Cortisol → ↓GnRH enters from the band's edge (see [3.1.1](#311-hypothalamus-and-pituitary-wiring)). |
| Pituitary | LH, FSH, prolactin | GnRH → ↑LH and GnRH → ↑FSH (two arrows). Prolactin is a pituitary hormone and its card sits in this band; it brakes the axis at the hypothalamus, PRL → ↓Kp. |
| Testes | Leydig cells → testosterone (T); Sertoli cells → inhibin B | LH → ↑T (via the Leydig cells), FSH → ↑inhibin B (via the Sertoli cells). A small note: the testes also secrete some E2 and DHT directly, but most of both comes from peripheral conversion (Target tissues band). |
| Blood transport | Total T → ↑SHBG-bound T, ↑free T, ↑albumin-bound T; SHBG-bound T ⇄ free T ⇄ albumin-bound T; SHBG and albumin concentration cards; bioavailable T bracket | See [3.2](#32-blood-transport). |
| Target tissues | free T → androgen receptor (AR); free T → ↑DHT → AR; free T → ↑E2 → estrogen receptors | See [3.3](#33-target-tissues). |
| Feedback | E2 → ↓Kp (`Hypothalamus·ARC`) ⟲; inhibin B → ↓FSH | Drawn as return arrows, visually distinct from forward drive; inhibin B's is a dashed line from the Inhibin B card to FSH. |

The `(site · subsite)` labels (ARC, POA—ME, POA) appear where the band has
room.

DHEA-S and ferritin are **not shown at all** — no nodes, no "Related" strip.

### 3.0 Edges

The full HPG edge set, mirroring the HP Axis page's chains
(`↑PRL → (Hypothalamus·ARC)↓Kp → (Hypothalamus·POA—ME)↓GnRH → (Pituitary)↓LH/FSH → (Testes)↓T`,
`↑T → {aromatization·fat}↑E2 → (Hypothalamus·ARC)↓Kp → … ⟲`,
`↑Cortisol → (Hypothalamus·POA)↓GnRH → …`) plus the transport and tissue
edges the diagram adds:

| Edge | Site / process | Kind |
| --- | --- | --- |
| Kp → ↑GnRH | `Hypothalamus·POA—ME` | forward |
| GnRH → ↑LH, GnRH → ↑FSH | `Pituitary` | forward |
| LH → ↑T, FSH → ↑inhibin B | `Testes` | forward |
| total T → ↑free T, ↑albumin-bound T, ↑SHBG-bound T | blood | binding |
| SHBG → ↑SHBG-bound T, albumin → ↑albumin-bound T | blood | binding |
| SHBG → ↓free T | blood | binding |
| SHBG-bound T ⇄ free T ⇄ albumin-bound T | blood | exchange (no mark) |
| free T → AR, DHT → AR, E2 → estrogen receptors | tissue | receptor (no mark) |
| free T → ↑DHT | `{5α-reduction}` | forward |
| free T → ↑E2 | `{aromatization·fat}` | forward |
| E2 → ↓Kp ⟲ | `Hypothalamus·ARC` | feedback — T's feedback reaches the hypothalamus through aromatization to E2 |
| inhibin B → ↓FSH | `Pituitary` | feedback (dashed) |
| PRL → ↓Kp | `Hypothalamus·ARC` | crosstalk |
| Cortisol → ↓GnRH | `Hypothalamus·POA` | crosstalk, side input from the adrenal (HPA) axis |

There is **no direct PRL → GnRH edge**, no PRL → LH or FSH edge, and no direct
T → GnRH or T → LH/FSH edge.

### Edge notation

The HP Axis page's ([2](#2-implementation-approach)). Every connector is a
plain **→**, "acts on / travels to"; there is no ⊣, no flat bar end and no red
inhibitory line anywhere in the view. The effect is written as **↑** or **↓**
immediately before the target signal, on the connector next to the target, and
belongs to that signal, not to its node: **GnRH → ↑LH** means when GnRH rises,
LH rises (stimulates); **PRL → ↓Kp** means when prolactin rises, kisspeptin
falls (suppresses). An arrow that ends at a receptor rather than a signal
(→ AR, → estrogen receptors) carries no mark, and the ⇄ between the transport
pools is exchange, not a response, so it carries none either. One deliberate
difference from the HP Axis page: that page tints its ↑/↓ in the accent color,
while this view leaves them uncolored.

Beside the diagram, a **How to read this** legend:

- **→** acts on.
- **↑B**: B rises when the source rises — e.g. GnRH → ↑LH.
- **↓B**: B falls when the source rises — e.g. PRL → ↓Kp.
- **⟲** closes a feedback loop; `(site · subsite)` names where an edge acts,
  `{process}` a conversion rather than an anatomical node.
- These edge marks describe how the pathway responds, **not** whether the
  user's value is high or low — the status colors show that. The ↑/↓ glyphs
  are therefore never colored (plain text color, never a status token), so
  they cannot be read as status.
- Line thickness in three steps — **thin** (low third of the range or below
  it), **medium** (middle third), **thick** (high third or above it) — and
  **grey** for not measured / not computable ([6.2](#62-pathway-thickness)).
- Greyed "–" = no measurement in this month or not computable, with every
  pathway that depends on it greyed too; status colors;
  "calculated" tag; and the caveats on DHT/T in [3.3](#33-target-tissues).

Plus a not-medical-advice disclaimer.

### 3.1 Biology corrections vs the mockups

These must hold regardless of any mockup:

- **Kisspeptin gates GnRH; GnRH drives both gonadotropins; prolactin brakes
  the axis through kisspeptin.** See
  [3.1.1](#311-hypothalamus-and-pituitary-wiring).
- **Total T feeds all three pools.** The total T card has an arrow to each of
  SHBG-bound, free and albumin-bound T (→ ↑ on each), not to free T alone.
- **The three transport pools are in constant equilibrium.** Total T =
  SHBG-bound + albumin-bound + free (+ negligible other binders). They are
  drawn as two-way arrows, **SHBG-bound ⇄ Free T ⇄ Albumin-bound**, never as
  one-way flows into free T.
- **Binding arrows raise their pools; only SHBG → ↓free T lowers one.**
  SHBG → ↑SHBG-bound T and albumin → ↑albumin-bound T are binding arrows. The
  one ↓ from SHBG sits on its arrow to the **free T** card, never on the
  SHBG-bound pool.
- **Only free T enters the cell, and it is drawn once.** Free T appears as a
  single card in the Blood transport band, never repeated in Target tissues,
  and that one card has the single arrow into the Target tissues band, where
  it splits into the three branches of [3.3](#33-target-tissues). SHBG-bound
  and albumin-bound T reach tissues only by dissociating back into free T.
- **T's feedback runs through E2**: E2 → ↓Kp, drawn from the E2 card up to
  Kp, closing the loop (⟲).
- **Inhibin B's feedback is a dashed line, inhibin B → ↓FSH**, from the
  Inhibin B card to FSH.
- **Example and test numbers must be physiologically consistent** — in
  mockups, fixtures, showcase data and screenshots alike: the three pools sum
  to total T, and free T is about 1–3% of total T (albumin-bound roughly
  30–50%, SHBG-bound the rest).
- **Free, albumin-bound and SHBG-bound T are calculated, not "not
  measured".** They render as calculated values with a "calculated" tag, and
  fall to the missing state (greyed "–", [5](#5-missing-data)) only when they
  cannot be computed for that month.
  Direct free T immunoassays are unreliable, which is why the calculated
  values are used.
- **Enzyme labels**: 5α-reductase on free T → ↑DHT, aromatase on free T → ↑E2.
- **E2 and DHT are mostly peripheral**: some of each is secreted by the testes
  directly, most comes from conversion in target tissues.

#### 3.1.1 Hypothalamus and pituitary wiring

- **Kp → ↑GnRH**: kisspeptin (Kp) is an intermediate node in the Hypothalamus
  band, released in the arcuate nucleus (`Hypothalamus·ARC`) and acting on the
  GnRH neuron (`Hypothalamus·POA—ME`). It is never measured, so its card
  always shows a greyed "–".
- **GnRH → ↑LH and GnRH → ↑FSH**: two separate arrows from the GnRH card, one
  to each gonadotropin, each marked ↑ at its target.
- **Prolactin sits in the Pituitary band**, beside LH and FSH — it is secreted
  by the anterior pituitary, so its card is never placed in the Hypothalamus
  band.
- **PRL → ↓Kp**: one plain arrow from the Prolactin card *up* to Kp, marked ↓
  at Kp, replacing any direct prolactin → GnRH arrow. High prolactin lowers
  kisspeptin and so GnRH pulses, LH, FSH and, downstream, T — one cause of
  secondary hypogonadism. It is a brake at the hypothalamus, not feedback from
  T.
- **No arrow from prolactin to GnRH, LH or FSH.** Its effect on them runs only
  through Kp.
- The hypothalamus in turn restrains prolactin tonically via **dopamine**.
  This is stated in the "How to read this" text and the prolactin hover; no
  dopamine node or arrow is drawn.
- **Cortisol → ↓GnRH** (`Hypothalamus·POA`): a crosstalk edge from a Cortisol
  card drawn as a side input at the Hypothalamus band's edge, labelled as
  coming from the adrenal (HPA) axis; sustained high cortisol (stress)
  suppresses GnRH and so LH/FSH and T. Cortisol is already in the catalog:
  `2143-6` (Cortisol [Mass/volume] in Serum or Plasma, `ug/dL`, the primary)
  and `14675-3` (its `[Moles/volume]` variant, `nmol/L`, `aliasOf` `2143-6`),
  so the card reads either code with no catalog change. No CRH, ACTH or
  adrenal node is drawn ([9](#9-out-of-scope)).

### 3.2 Blood transport

- Three pool cards, all **calculated**, all in **nmol/L**, each with a
  "calculated" tag:

  | Pool | Calculation |
  | --- | --- |
  | Free T | cFT, Vermeulen (the `cft` index's equation, shown in nmol/L) |
  | Albumin-bound T | cFT × K_alb × [albumin] |
  | SHBG-bound T | total T − cFT − albumin-bound |

- The albumin-bound and SHBG-bound pools are new **derived values**, computed
  by reusing `vermeulenFreeT` and its constants (`KA_ALBUMIN`, `albuminMolL`)
  from `web/src/data/indexDefs.ts` rather than restating the equation. They
  carry **no reference ranges** — none is invented — so they render with the
  neutral status color.
- A **total T** card (measured) with an arrow to each of the three pools,
  total T → ↑SHBG-bound T, ↑free T, ↑albumin-bound T.
- An **SHBG** concentration card sits beside the SHBG-bound pool and an
  **albumin** card beside the albumin-bound pool; both are measured markers.
  SHBG → ↑SHBG-bound T and albumin → ↑albumin-bound T are binding arrows.
- **SHBG → ↓free T**: a plain arrow to the free T card, marked ↓ at free T
  (more SHBG, less free T).
- A bracket groups free + albumin-bound as **Bioavailable T**, carrying the
  `biot` index's value.
- **No default albumin in this view.** Every pool calculation takes the
  albumin measured in the selected month (its latest value there,
  [4](#4-month-selection)). If albumin was not measured, the
  albumin card is greyed "–", and so is everything that needs albumin — the
  free T pool (Vermeulen's equation takes albumin), the albumin-bound and
  SHBG-bound pools and the Bioavailable T bracket — together with every
  pathway that depends on them. This deliberately differs from the `cft` and
  `biot` indices elsewhere in the app (Results, "What's in range", the index
  popup), which fall back to `DEFAULT_ALBUMIN_GDL`, 4.3 g/dL.

### 3.3 Target tissues

Three branches, all starting from the single arrow out of the Blood transport
band's free T card (free T is not drawn again here):

1. **free T → androgen receptor (AR)** directly.
2. **5α-reductase** enzyme label, with the **DHT/T** ratio chip (`dhtt`)
   beside it: free T → **↑DHT** → AR (a stronger signal than T).
3. **aromatase** enzyme label (`{aromatization·fat}`), with the **T/E2** ratio
   chip (`te2`) beside it: free T → **↑E2** → estrogen receptors; the E2 card
   also carries the feedback arrow E2 → ↓Kp.

- DHT/T **rises** with 5α-reductase activity; T/E2 **falls** with aromatase
  activity, and its chip's caption says "low = more aromatization".
- A small caption: 5α-reductase mainly in prostate, skin and hair follicles;
  aromatase mainly in fat, brain and bone.
- Ratios use **total T**, as the app's indices already do (`tlh`, `dhtt`,
  `te2`). Never invent non-standard ratios (e.g. DHT/cFT) or ranges for them.
- "How to read this" says that serum DHT understates tissue DHT (most DHT is
  made and acts inside the cell — intracrine), so DHT/T is a rough signal.

## 4. Month selection

- A **‹ month ›** stepper, **shared across axes**, labelled by month (e.g.
  "May 2026"). It steps **by month**, through only the months that have at
  least one measurement of a marker the current axis shows (any node's marker
  or an input to an axis index or pool calculation); months without one are
  skipped. It replaces both the timeline slider and a date dropdown.
- **Within a month, each marker uses its latest value in that month** — so one
  month with several reports needs no further choice. Indices, ratios and
  pools are computed from those per-marker values, and a node's hover names
  the date of the reading it shows ([7](#7-interaction)).
- Defaults to the latest such month; each arrow is disabled at its end.
- Changing the month animates arrow thicknesses to the new month's values.

## 5. Missing data

- Wherever there is no measurement in the selected month, the node shows a
  greyed "–" value. No carry-forward of a value from an earlier month.
- The same holds for a calculated value (index, ratio or pool) that cannot be
  computed for that month.
- Every pathway (arrow) that depends on a greyed node is greyed too.
- **Never-measured nodes are exempt from that propagation**: GnRH is drawn
  neutral, never as "missing"; Kp always shows a greyed "–" (it is never
  measured) but greys no arrow and is never hidden — an arrow through GnRH or
  Kp is greyed only when its measured source is.
- Cortisol follows the ordinary rule: greyed "–" when not measured in the
  selected month, and its → ↓GnRH arrow with it.

## 6. Visual encoding

### 6.1 Numbers

- Every value renders at the **same size and weight**; there is no
  value-to-size scaling.
- Status color (the app's status tokens, `COLOR.statusOk` / `statusWarn` /
  `statusBad` / `statusNone`) is the only per-value encoding on a card.
- Reference range: the report's printed range where present, else the
  catalog's. No range → neutral color with a note in the hover.

### 6.2 Pathway thickness

- Line thickness is the diagram's only magnitude encoding, and it is always
  on. An arrow's thickness follows the ratio index that describes that
  pathway where one exists, else the target node's value:

  | Pathway | Driven by |
  | --- | --- |
  | LH → ↑T | `tlh` (T/LH) |
  | free T → ↑DHT | `dhtt` (DHT/T) |
  | free T → ↑E2 | `te2` (T/E2) |
  | any other | target node's value against its reference range |

- **Three steps, no continuous scale.** The driving value's range — a marker's
  reference range ([6.1](#61-numbers)), or a ratio index's ok-zone band — is
  split into thirds:

  | Step | Driving value |
  | --- | --- |
  | thin | below the range, or in its low third |
  | medium | in its middle third |
  | thick | in its high third, or above the range |
  | grey | not measured / not computable for the month ([5](#5-missing-data)) |

  A value with no range (the calculated albumin- and SHBG-bound pools, a ratio
  with no band) and a never-measured target (Kp, GnRH) draw **medium**. A
  boundary value takes the higher step.

- A ratio-driven arrow shows its ratio as a chip; for free T → ↑DHT and
  free T → ↑E2 the chip sits beside the enzyme label
  ([3.3](#33-target-tissues)). Thickness and the ↑/↓ mark are independent:
  thickness is the user's magnitude, the mark the pathway's direction of
  response.

### 6.3 Controls

- **Measured only | Full pathway** switch — Measured only hides nodes and
  arrows with no data in the selected month; Full pathway draws the whole
  axis with missing states. GnRH and Kp stay in both modes, so no chain
  breaks.
- The Cortisol side input obeys it like any node: with Measured only, the
  Cortisol card and its → ↓GnRH arrow appear only when cortisol was measured
  in the selected month; with Full pathway they are always drawn, greyed "–"
  when not measured.

Dropped: the "Relative to reference ranges" toggle (thickness is always on),
the search box, and the user avatar (the app has no accounts).

## 7. Interaction

- Hover a node → value, unit, the date of that reading (its latest in the
  month), laboratory, reference range (and its
  source: printed or catalog); for a calculated pool, its formula and inputs;
  for Kp and GnRH, that they are not measured in clinical practice.
- Click a node → the existing analyte popup (index popup for `cft` / `biot`
  and the ratio chips). Kp and GnRH open nothing.
