# Record laboratory prices for the tests each laboratory sells

Goal: the app knows what a test costs at a given laboratory.

The request, in the user's words:

> laboratories prices

## What shipped

- **The registry holds the prices.** `web/public/data/laboratories.json` is the
  laboratory registry and the single source of truth for prices, in the spirit
  of [ADR-0010](../tech/decisions/adr-0010-analyte-catalog-is-the-source-of-truth.md).
  Each laboratory has an `id`, `name`, `locale`, `currency`, `pricesAsOf`,
  `source` and `prices`. Each price line has a `label`, a `price`, a `covers`
  list of every catalog LOINC it can satisfy, an optional `panelId` for a bundle
  that is a `panels.json` group, and an optional `note`. Esculab is seeded from
  the prices the user entered: ten products in UAH as of 2026-09-10.
  [`docs/content/laboratory-prices.md`](../content/laboratory-prices.md) keeps
  the mapping reasoning and points at the JSON rather than copying it.
- **Synevo Ukraine was removed.** Its entry had two product codes and no
  prices, and nothing read it.
- **Schema and conformance.** `web/public/schema/laboratories-1.schema.json`
  (draft 2020-12, closed objects). `web/test/reference-data.test.ts` validates
  the file and checks unique ids and labels, positive prices, every covered
  code in the catalog, and that a bundle naming a group covers exactly that
  group's codes, so the FBC line cannot drift from `fbc`.
- **Costing.** `quoteSchedule` in `web/src/data/labPricing.ts` folds each
  scheduled code through `ALIAS_TO_PRIMARY`, takes the cheapest line covering
  it, charges each line once, and returns the total, the currency, the lines
  charged and the codes no line covers. Tested in
  `web/test/lab-pricing.test.ts`.
- **In the Scheduled column header.** Beneath the month pill and select-all
  box, a "No lab" / laboratory select and, once one is chosen, the total of the
  whole schedule at that laboratory ("517 UAH"), a muted "N not priced" when
  some scheduled code has no price, and the charged lines in the total's
  tooltip. It recalculates as rows are scheduled and the laboratory changes.
- **Persisted with the schedule.** The chosen laboratory id is an optional
  `lab` in `bloodtests_scheduled_v1`, kept backward compatible the way `month`
  is: an absent key means none, a malformed or unknown id loads as none, and
  older payloads load unchanged. Panel Detail and All Observations read it
  from the shell through `ScheduleLabContext`, so both show the same total.

## How the open questions were settled

- **What is priced**: both single tests and bundles, as price lines that cover
  one or many codes. Costing takes the cheapest line per code, not the cheapest
  combination of lines.
- **Mapping to LOINC**: `covers` lists every code a line can satisfy, which
  expresses a bundle, an ambiguous label (glucose covers serum/plasma and whole
  blood) and a code sold in several products. Mass/molar pairs list the mass
  primary and costing folds aliases.
- **Currency and scope**: one currency per laboratory, no per-country or
  per-branch pricing.
- **Dated**: one `pricesAsOf` per laboratory, overwritten when prices change.
- **Source**: a curated file shipped with the app, public reference data. No
  network fetching.
- **Travel with reports**: no. Prices are not in the interchange envelope,
  exports or share links. (Since then Account's "Export all data" zip carries
  a `laboratory-prices.json` copy, which "Import all data" never restores —
  the shipped registry wins.)

## Still open

- **Cheapest combination.** A test sold alone and inside a bundle is priced per
  code, so scheduling it with one other bundle member charges both.
- **Report `lab` to registry.** Reports still name their laboratory as free
  text in several spellings, and nothing resolves that to a registry id.
- ~~**Comparison across laboratories.** Only Esculab is priced, so there is
  nothing to compare yet, and the header costs one laboratory at a time.~~
  Settled after closing: Medis and Synevo were priced the same day, and
  Scheduled Visits (`#plan`) shows one price column per laboratory over a
  Total row.
- **Price history and scope.** No history, per-branch or per-city prices.
- **Private prices.** A negotiated price or discount would belong in
  localStorage, layered over the public file. Not built.
- **Esculab's own gaps.** Whether its FBC includes the differential, and
  whether its LDL-C is a direct assay, for which the catalog has no code yet.
- **Concern.** This belongs under the "Scheduler" draft in
  [`docs/concerns.md`](../concerns.md). Set `concern` once that becomes a `Cn`.
