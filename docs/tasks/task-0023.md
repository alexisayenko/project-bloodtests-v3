# Monitoring panels controls & customization — name toggle, status filters, and edit panels mode (hide/show, custom panels, drag-and-drop reorder)

The **Monitoring Panels** page (`#panels` / `PanelsGridView`) renders condition-oriented cards containing biomarker and index chips with color-coded status dots.

Currently, marker chips always display the full descriptive name (`test.full`), all declared markers in each panel are shown regardless of whether they have been tested or what their latest status is, and panels are presented in a fixed static order without the ability to hide irrelevant panels or create new ones.

This task adds rich display controls and panel management to the Monitoring Panels view:
1. **Name Display toggle**: `Short Name` vs. `Friendly Name` (display name).
2. **Status Filter toggles**: Multi-state toggles for `Not Tested` (grey), `In Range` (green), `Unknown / Borderline` (yellow), and `Out of Range` (red).
3. **Edit Panels view**:
   - **Hide / Show panels**: Toggle visibility for individual panels to reduce clutter.
   - **Create custom panels**: Define new panels with chosen markers, icon, color, and description.
   - **Reorder panels by dragging**: Drag-and-drop repositioning of panel cards in the grid.

---

## 1. Name Display Control (`ShortName` vs. `FriendlyName`)

Provide a segmented toggle or button group in the toolbar:

- **Short Name**:
  - Observations: Renders `test.short` (e.g. `ALT`, `AST`, `TSH`, `HbA1c`, `LDL-C`, `Ferritin`).
  - Indices: Renders `def.nameCompact` (e.g. `FIB-4`, `HOMA-IR`, `AIP`, `De Ritis`).
  - Ideal for dense overview, power users, and clinical familiarity.
- **Friendly Name (Display Name)**:
  - Observations: Renders `test.full` (e.g. `Alanine aminotransferase`, `Thyroid-stimulating hormone`, `Glycated hemoglobin`).
  - Indices: Renders `def.name` (e.g. `Fibrosis-4 (FIB-4) index for liver fibrosis`, `Homeostatic Model Assessment of Insulin Resistance`).
  - Ideal for readability, patient education, and clear terminology.

Default mode: `Friendly Name` (or last chosen preference), persisted in `localStorage`.

## 2. Status Filter Toggles (`Not Tested`, `Green`, `Yellow`, `Red`)

Allow users to focus on specific clinical outcomes across panels by toggling statuses on/off:

| Status Key | Visual Indicator | Status Meaning | Latest Result Condition |
| --- | --- | --- | --- |
| **Not Tested** | Grey dot (`#94a3b8`) | No measurements recorded | No results found across all uploaded reports |
| **In Range** | Green dot (`#16a34a`) | Normal / within range | Latest result within reference limits (`in-range` / `ok`) |
| **Unknown** | Amber dot (`#f59e0b`) | Borderline / no reference range | Reported without reference range or intermediate zone (`unknown` / `warn`) |
| **Out of Range**| Red dot (`#dc2626`) | Flagged abnormal | Latest result outside reference limits (`out-of-range` / `bad`) |

### Interaction Model:
- **Multi-select toggles**: Users can enable/disable any combination:
  - *Example 1*: Enable only `Red` + `Yellow` to immediately highlight all abnormal and borderline markers across all panels.
  - *Example 2*: Toggle off `Not Tested` to see only markers with actual historical data.
- **Count badges**: Each toggle displays the total count of markers currently matching that status across all loaded reports.
- **Quick presets**:
  - "All" (activates all 4 statuses).
  - "Abnormal only" (activates Red + Yellow).
- **Filtering effect**:
  - Within each panel card, chips matching unchecked statuses are filtered out.
  - Marker count badge in panel header reflects visible / total (e.g. `2 of 8 markers`).
  - If a panel card has no markers matching the active filter, display a subtle empty indicator or allow hiding empty cards.

## 3. Allow to Edit Panels View (`Edit Panels Mode`)

Add an **Edit Panels** button to the toolbar to customize the panel grid:

### 3.1 Hide / Show Panels
- In edit mode, each panel card displays a visibility toggle (e.g. Eye icon `👁 Visible` / `🚫 Hidden` or checkbox).
- Alternatively, provide an "Organize Panels" drawer/modal listing all panels with checkboxes to show/hide.
- Hidden panels are removed from the default grid and sidebar navigation, letting users focus only on panels relevant to their health monitoring.
- A "Hidden Panels" counter / drawer allows unhiding any panel at any time.

### 3.2 Create Custom Panels
- **"+ New Panel"** button in edit mode or toolbar.
- Builder modal / interface:
  - **Panel Name & Category**: e.g., "Longevity Protocol", "Cardiovascular Deep-Dive".
  - **Icon & Accent Color**: Visual icon selector and theme color.
  - **Description**: Target condition or clinical rationale.
  - **Marker Picker**: Search and select any analyte from the catalog (by LOINC, display name, or short code) or computed index.
- Custom panels appear alongside standard panels in the grid with an edit/delete option.
- Stored locally in browser storage and round-tripped through backup JSON/zip export.

### 3.3 Reorder Panels by Dragging (Drag-and-Drop)
- In edit mode, panel cards become draggable with a visible grab handle (`GripVertical`) and hover/active states.
- Reordering panels updates the grid layout in real time.
- The custom sort order (`panelOrder: string[]`) is persisted in `localStorage`.
- Provide accessible keyboard reorder controls (Move Earlier / Move Later) as a fallback.
- "Reset Order" action to restore standard clinical grouping.
