# Decide whether the free-T percentage indices take status from Labcorp's 1.5–3.2 % interval

The three free-testosterone percentage indices in `INDEX_DEFS`
(`web/src/data/indexDefs.ts`) — `cftpct` (Vermeulen), `ftpct` (measured) and
`cftlhpct` (Ly & Handelsman) — carry no status bands. Each quotes Labcorp's
adult male interval, 1.5–3.2 % (test 500726, retrieved 2026-09-16), for
orientation only, and each says why: the app's bands need a separate
borderline limit, and the interval gives a single low–high range.

## What has to be decided

- **Whether to band them at all.** Labcorp's interval is for the fraction
  measured by equilibrium dialysis. `cftpct` is a calculation that Fiers et al.
  (2018) found runs a median 19 % above dialysis in men; `cftlhpct` ran closest
  (median ratio 1.00, 0.69–1.42); `ftpct` is only as good as the lab's free-T
  row, usually a direct analog immunoassay the Endocrine Society says not to
  use, which reads well under the interval. One interval may fit one index and
  mislead on another.
- **How bands would take a plain low–high range.** `cut` / `hi` today express
  a two-limit band with a borderline zone; a single reference interval has no
  borderline limit. Either the band model grows a plain in-range /
  out-of-range form, or a borderline limit is chosen, which would need its own
  source.

## Out of scope

`biotpct` (bioavailable T as % of total) stays unbanded: no reference interval
for it was found in a major reference laboratory's catalog.
