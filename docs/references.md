# External Standards & References

Authoritative standards, coding systems, terminology vocabularies, and specification repositories used or referenced by project-bloodtests-v3.

## LOINC (Logical Observation Identifiers Names and Codes)

International standard for identifying health measurements, laboratory observations, and clinical documents.

- [LOINC Official Website](https://loinc.org/) — Official home for LOINC search, documentation, and code releases.
- [LOINC on Wikipedia](https://en.wikipedia.org/wiki/LOINC) — Encyclopedic overview of LOINC history, purpose, and structure.
- [LOINC on GitHub](https://github.com/loinc) — Official GitHub organization for LOINC tools and open-source projects.

## UCUM (Unified Code for Units of Measure)

Code system intended to include all units of measures being contemporarily used in international science, medicine, and engineering.

- [UCUM Official Website](https://ucum.org/) — Official home and specification for the UCUM standard.
- [UCUM at NLM (National Library of Medicine)](https://ucum.nlm.nih.gov/) — NLM service, tools, and web API for validating and converting UCUM syntax.
- [UCUM on GitHub](https://github.com/ucum-org/ucum) — Specification sources and tooling maintained by the UCUM organization.
- [Unified Code for Units of Measure on Wikipedia](https://en.wikipedia.org/wiki/Unified_Code_for_Units_of_Measure) — Encyclopedic summary of the UCUM syntax rules and adoption.

## Chemical Identifiers

- [CAS Registry Number on Wikipedia](https://en.wikipedia.org/wiki/CAS_Registry_Number) — Overview of Chemical Abstracts Service registry numbers for uniquely identifying chemical substances, molecular structures, and analytes.

## HL7 (Health Level Seven International)

Framework and standards for the exchange, integration, sharing, and retrieval of electronic health information.

- [HL7 on Wikipedia](https://en.wikipedia.org/wiki/HL7) — Background on the Health Level Seven organization and interoperability standards.
- [HL7 Standards Master Grid](https://www.hl7.org/implement/standards/index.cfm?ref=nav) — Official catalog and implementation guides for all HL7 standards.
- [HL7 on GitHub](https://github.com/hl7) — Official HL7 organization repositories.

## FHIR (Fast Healthcare Interoperability Resources)

Next-generation healthcare interoperability standard combining features of HL7 v2, HL7 v3, and CDA, leveraging modern RESTful web APIs and JSON/XML representations.

- [HL7 FHIR Official Specification](https://www.hl7.org/fhir/) — Official HL7 FHIR current standard specification and resource definitions (e.g. `Observation`, `DiagnosticReport`).
- [Fast Healthcare Interoperability Resources on Wikipedia](https://en.wikipedia.org/wiki/Fast_Healthcare_Interoperability_Resources) — Encyclopedic overview of FHIR architecture and industry adoption.
- [FHIR Foundation](https://fhir.org/) — Community portal, tooling directory, and implementation guides.
- [eCQI Resource Center: About FHIR](https://ecqi.healthit.gov/fhir/about) — U.S. CMS and ONC guide on FHIR standards in healthcare data exchange and clinical quality.
- [HL7/fhir on GitHub](https://github.com/HL7/fhir) — Core specification build repository for HL7 FHIR.
- [FHIR Organization on GitHub](https://github.com/FHIR) — Open-source tooling, libraries, and reference implementations.
